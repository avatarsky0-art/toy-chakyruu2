# 💍 Мирбек & Мээрим — той чакыруу

Бир беттик үйлөнүү той чакыруусу. Бардык файл бир жерде — папка жок.

## GitHub Pages'ке коюу
1. Репозиторийге бул папкадагы **бардык файлды** жүктө (Add file → Upload files → баарын сүйрөп таштa)
2. Settings → Pages → Branch: `main` / `root` → Save
3. Шилтеме: `https://колдонуучу-атың.github.io/репозиторий-аты/`

## Өзгөртүү
Баары `index.html` ичинде. `<script>` бөлүгүнүн башындагы `CONFIG`:
- `weddingDate` — той датасы (ай 0дон башталат: 10 = ноябрь)
- `whatsappPhone` — ырастоо үчүн номер
- `qrData` — QR-коддун ичиндеги маалымат

Түстөр `<style>` бөлүгүндөгү `:root` ичинде.
Сүрөттөрдү `photo1.jpg`, `photo2.jpg`, `photo3.jpg` деген ат менен алмаштыр, ырды — `song.mp3`.
